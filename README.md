# 🏥 Hospital Management System

A web-based **Hospital Management System** designed to simplify hospital operations such as patient registration, appointment booking, and doctor management.
The system provides an easy interface for managing hospital services and improving communication between patients and doctors.

## 📌 Project Overview

The Hospital Management System helps hospitals manage patient information, doctor details, and appointment scheduling in a structured way.
It reduces manual work and makes hospital operations more organized and efficient.

## 🚀 Features

* Patient Registration
* Doctor Information Management
* Appointment Booking System
* Time Slot Selection
* Appointment Confirmation
* User-friendly Interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
